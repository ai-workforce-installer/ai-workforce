This test runs without Notion or Gmail tools, so the run may honestly say near the top that its Result is Partial because nothing could be saved. A title and one such Result line before the "Handled" line are fine.

PASS if the first substantive thing in the report written for the owner is what the team handled (a "Handled:" line or a sentence to that effect), followed by today's priorities, and the run's own bookkeeping (Run ID, start time, how each part ran, verification, sources, usage) appears only after the owner-facing part: at the end, inside a section marked as details or collapsed, or described as going into the run record.
FAIL if the owner's report begins with a Run ID, a start time, "Status: Running" or a "Reading taken" line, or puts verification, sources or coverage detail ahead of what was handled and today's priorities.
