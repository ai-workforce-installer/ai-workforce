Operations this connection offers (name: kind, what it does):
- search-conversation: read
- get-messages: read
- get-contact: read
- add-tags: write, adds tags to a contact (params: contactId, tags)
- remove-tags: write, removes tags from a contact (params: contactId, tags)
- update-opportunity: write, changes an opportunity, including its pipeline stage (params: id, pipelineStageId)
- send-a-new-message: write
- delete-contact: delete
