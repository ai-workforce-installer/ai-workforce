# If the numbers a job needs aren't where the team can read them

Read this only when a job needs figures (invoices, payments, ad or sales results) and Where things live names no source for them, or the source it names has nothing new.

1. **A connection first.** Before asking for any export, search the connector registry for the place the numbers live (Stripe, PayPal, QuickBooks, Meta Ads). If it is there, offer it once: "Your <app> account can be connected, so the team reads the numbers directly. Connect it?" Declined: note that under Where things live and don't offer it again.
2. **Otherwise the owner names one place, once:** a folder in their file app or a Notion page. Save it under Where things live. Every later run reads the newest file there without asking again; nothing new there is said in one line, with the newest file's date.
3. **A pasted or attached export is welcome at any time.** Read it as it is, use it for this run, and keep its summary (period, totals, what it didn't include) in the run record. Never ask for the same columns twice: note once, under Where things live, what that export holds.
4. **No spreadsheet templates.** Notion stays the workspace: never create a sheet, or ask the owner to keep one.

In a scheduled run nothing is asked: steps 1 and 2 become the report's one question, and a figure it couldn't read is Unavailable, never estimated.
