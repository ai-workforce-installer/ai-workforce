# If this is the urgent-only check

Read this only when a recurring inbox task's Owner's additions begin `Urgent-only check`, or the owner asks for one ("anything urgent?").

An optional mid-afternoon look, off unless the owner turned it on. It is not a triage: the morning run still reviews everything, and this run's Result is judged against this check only.
1. **Window:** from the inbox bookmark to now. The bookmark is not moved.
2. **Senders, subjects and previews only,** from one search, every page. Look for four things: a security alert, a failed payment, an outage or failure the business relies on, a deadline within 48 hours. Open a thread only to confirm one. The owner's corrections apply as always.
3. **Draft nothing and queue no decision.** Each urgent item becomes, or updates, one open-work row, so the morning run takes it from there.
4. **Notify only when something is urgent:** one notification naming it, with its link. Nothing urgent: a one-line record ("Urgent-only check: nothing urgent in 37 emails") ending `Notified: not requested (nothing urgent)`, and stay quiet.

Its record is an Inbox triage record marked `Coverage: urgent-only`, with `Completed through: not moved (urgent-only check)`.
